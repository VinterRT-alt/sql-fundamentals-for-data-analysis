# 🧠 Ejercicios SQL - Tabla `customers` (Base de datos classicmodels)

Este repositorio contiene una serie de ejercicios prácticos de SQL resueltos, enfocados en la tabla `customers` de la base de datos de ejemplo **classicmodels**. Los ejercicios abarcan desde consultas básicas hasta agregaciones con `GROUP BY`, filtros con `HAVING`, y uso de `DISTINCT`, `LIKE`, `IS NULL`, entre otros.

## 📌 Contenido

- Consultas de exploración y conteo
- Filtrado por ciudad, país, y valores nulos
- Identificación de países con un solo cliente
- Búsqueda de patrones en teléfonos (prefijo entre paréntesis)
- Obtención de valores únicos para imprenta
- Análisis de comerciales con clientes en rango de crédito
- Agregaciones por ciudad y país con condiciones
- Promedios de crédito por país con filtro posterior

## 🛠️ Requisitos

- Tener instalado **MySQL** (o cualquier motor SQL compatible).
- Contar con la base de datos `classicmodels`. Puedes descargarla desde [aquí](https://www.mysqltutorial.org/mysql-sample-database.aspx) e importarla.
- Un cliente SQL (MySQL Workbench, DBeaver, línea de comandos, o la extensión de VSCode)
